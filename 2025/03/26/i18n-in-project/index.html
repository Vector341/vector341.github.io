# 库

该插件是一个个人项目，smb 课在插件的基础上做了大量修改，增加了很多配置项，形成了现在这套方案。

# 原理

基本原理

通过 AST 提取源码中的多语言文本，生成特定格式的 json，进入翻译流程，将翻译后的文本重新输入到 intl 函数中
